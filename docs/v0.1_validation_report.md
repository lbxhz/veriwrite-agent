## 五份内置样例

| 样例 | 主要覆盖点 | 规则模式结果 |
| --- | --- | --- |
| 完整课程要求 | 字数、文献、外文比例、格式、歧义与模板题目 | 识别 15000 字、60 篇文献；因真实主题缺失进入用户确认 |
| 外文比例表达 | 三分之一换算与近年文献偏好 | 可进入确认 |
| 指定章节结构 | 章节、原创分析、禁止摘要罗列 | 可进入确认 |
| 图表与格式要求 | 图件、公式、字体、纸张和行距 | 可进入确认 |
| 冲突字数表达 | “左右”与“以上”的差异 | 保留歧义，要求用户确认 |

以上五个样例均通过 `prepare_review_from_path()` 运行，并作为参数化自动化测试固定下来。

## 真实课程要求文件

文件：`【附件2】硕士学位课程《研究方向文献综述》要求.doc`

旧版 DOC 通过与 UI 上传相同的临时文件流程，由本机 Microsoft Word
只读转换后解析：

- 提取文本：2661 个字符；
- 最低字数：15000；
- 最低参考文献数：60；
- 最低外文文献数：20；
- 规则模式：成功，因真实研究主题仍未知而保留 1 个阻塞项；
- DeepSeek 双路模式：LLM 路径成功，输出 6 个实质差异字段和 7 个阻塞项；
- 用户需要逐项裁决冲突，系统不会让任一路径静默覆盖另一条路径。

同内容 DOCX 和文本型 PDF 也成功提取，并得到相同的三项关键数量约束。

## UI 闭环

Streamlit 冒烟测试覆盖：

1. 工作台启动；
2. 选择默认样例并分析；
3. 展示运行指标、双路对照、冲突和完整性问题；
4. 填写真实研究主题并确认已知警告；
5. 调用确认服务和 Pydantic 复检；
6. 生成最终需求版本下载入口。

## 当前边界

- 图片和扫描 PDF 使用本地 OCR，单个 PDF 每次最多识别 30 个扫描页；
- OCR 置信度不是正确率，低置信度结果必须先核对提取文本；
- 旧版 DOC 自动转换依赖 Windows 和本机 Microsoft Word；
- 规则解析器是可重复的基线，不可能覆盖所有自然语言写法；新增真实样例应转成固定测试，
  由规则与 LLM 双路结果共同暴露遗漏；
- DeepSeek 调用依赖本地 `.env`，界面只显示模型和配置状态，不显示密钥；
- V0.1 只确认需求数据合同，不在此阶段执行文献身份和引用真实性验证。
