# V0.2.2：大纲引导的多主题文献选择

## 要解决的问题

V0.2.1 已经能验证文献身份，但“真实”不等于“适合最终综述”。旧实验的 20 篇文献主要
集中在气溶胶，温室气体与空气质量覆盖不足。V0.2.2 把要求、检索覆盖、文献真实性和最终
选择拆成不同职责。

```text
V0.1 已确认 RequirementSpec
    -> LLM 生成临时检索蓝图（主题、研究问题、检索词、主题配额）
    -> 用户检查、修改并确认临时检索蓝图
    -> 代码为每个主题建立独立检索计划
    -> Crossref 对同一主题的多条检索式公平轮询
    -> Crossref RIS + DOI.org 验证文献身份
    -> LLM 只评估真实题名/摘要与各主题的相关性
    -> 代码按“相关性 > 地大期刊等级 > 年份”选择并执行主题配额
    -> 文献矩阵与全文证据
    -> 根据真实证据修订为最终写作大纲
```

第一版大纲是 `provisional_search_blueprint`，作用是防止检索被单一关键词垄断。它不是最终
写作结构。最终大纲要在形成文献矩阵、了解真实证据分布后修订，否则容易先定结论再挑证据。

临时检索蓝图也不能由 LLM 生成后直接执行。用户需要先检查主题是否需要、主题间篇数是否
合理、年份和检索边界是否符合预期；确认后形成带确认人、确认时间和备注的
`ConfirmedLiteratureSearchBlueprint`。检索扩展器只接受确认版，草案不能调用 Crossref，
避免产生大量用户不需要的候选和 API 成本。

## 模型与代码的边界

| 判断 | 执行者 | 原因 |
|---|---|---|
| 章节主题、研究问题、英文检索词 | LLM | 需要语义理解与同义表达 |
| 查询轮询、候选预算、主题配额 | 确定性代码 | 必须稳定、可测试、可复现 |
| DOI 与 RIS 是否真实、字段是否完整 | 确定性代码 + 权威网络源 | 不能依赖模型记忆 |
| 题名/摘要与主题是否贴切 | 受限 LLM | 需要语义判断，但输入只能是已验证论文 |
| 最终排序与去重 | 确定性代码 | 用户指定的优先级必须严格执行 |

相关性评分器不能增加或修改 DOI，也不能判断文献真假、期刊等级。它必须原样返回全部输入
DOI，并为每篇论文覆盖全部蓝图主题；越界一次后允许修复，仍越界则停止。

## 选择优先级

对同一个主题的候选，排序键依次是：

1. 与主题及研究问题的相关性分数，从高到低；
2. 中国地质大学（武汉）2023 版对应学科期刊等级，T1 到 T6；
3. 发表年份，从新到旧；
4. DOI，仅用于完全相同条件下的稳定排序。

主题配额先于全局“凑满数量”。某个主题没有足够相关论文时，系统输出 `shortages`，不允许
其他主题静默占用它的名额。

## 期刊目录是软偏好，不是真实性判据

V0.2.0 默认把“不在地大目录”当作硬排除。真实回归发现温室气体主题扫描了 75 篇，却因
学科目录匹配失败而得到 0 篇候选。这混淆了两个概念：

- DOI/RIS 验证回答“这篇论文是否真实、元数据是否对应”；
- 地大目录回答“在指定学科的本地分类中是否有可用等级”。

V0.2.2 新增两种策略：

- `required`：兼容旧版或用户明确规定 T 级别的硬约束；
- `preferred`：默认策略。未分级论文可以入选，但在相关性相同时排在已分级论文之后，并
  显示 `ranking_status=not_found/ambiguous`。

因此，`UNRANKED` 不代表低水平或虚假，只代表当前本地目录无法给出该学科下的唯一等级。

## 真实回归

固定需求为 2022—2026 年大气遥感文献 20 篇，覆盖气溶胶、云、温室气体和空气质量。

| 指标 | V0.2.1 | V0.2.2 |
|---|---:|---:|
| 最终文献 | 20 | 20 |
| RIS + DOI 验证 | 20/20 | 候选 40/40，最终 20/20 |
| 主题配额 | 无 | 4 个主题各 5 篇 |
| 明确主题缺口 | 否 | 是，本轮无缺口 |
| 选择依据 | 发现顺序 | 相关性、期刊等级、年份 |

V0.2.2 最终等级分布为 T1 1 篇、T2 10 篇、T3 2 篇、未分级 7 篇。全部 20 篇均保留
Crossref RIS、DOI 解析证据、相关性得分、主题归属、期刊等级状态和选择理由。

本轮 40 篇候选中，29 篇的最佳主题相关性被 LLM 评分为 1.0，出现明显分数饱和。因此，
主题配额和最低相关性门槛已经有效，但同一主题内的细粒度语义排序仍未得到充分验证；不少
并列候选实际由期刊等级和年份决定顺序。

回归脚本具有阶段缓存：

- `v022_prefiltered_candidates.json`
- `v022_confirmed_blueprint.json`
- `v022_verification_cache.json`
- `v022_relevance_cache.json`

网络或模型调用中断后可以从未完成阶段继续，避免重复请求和重复消耗。

## 仍未解决的边界

- 题名和摘要相关只说明“值得进入候选池”，不证明正文支持某个具体论点；
- Crossref 类型为 `journal-article`，仍可能包含评论、社论等非首选材料；
- 地大目录是 2023 版本地分类，不是全球统一的期刊质量真值；
- 相关性评分仍需通过人工金标准评测，而不能只观察模型自评分数；
- 需要校准相关性分数，避免大量候选集中在 1.0，并识别评论、社论等非首选文献类型；
- 最终写作大纲、文献矩阵、全文证据卡属于后续阶段。

因此，V0.2.2 的完成标准是“真实、分主题覆盖、可解释地选出候选文献”，不是“已经可以
自动写出有证据支撑的完整综述”。
