# V0.2.0 文献发现与地大期刊分级设计

## 目标与边界

V0.2.0 接收 V0.1 已由用户确认的 `ConfirmedRequirementSpec`，自动生成检索计划，
从 Crossref 发现带 DOI 的期刊论文候选，并按照中国地质大学（武汉）2023 版期刊分类目录
执行确定性筛选。

本版本验证的是“候选文献身份信息能否进入可信候选池”，暂不判断论文与主题是否真正相关，
也不判断正文中的引用位置是否恰当。主题相关性与引用妥当性属于后续版本。

## 处理流程

1. `LiteratureKeywordPlanner`只让 LLM 完成语义任务：把已确认主题转换为关键词和
   Crossref 检索式，并从本地目录支持的学科中选择一个学科。
2. `LiteratureSearchPlan`用 Pydantic 检查 LLM 输出，固定最多扫描 300 篇、目标获得
   50 篇通过硬规则预筛的候选。
3. `CrossrefSearchProvider`调用 Crossref，获得 DOI、题名、作者、年份和期刊名等元数据。
4. `LiteratureDiscoveryService`按 DOI 去重，并执行文献类型和年份等硬规则。
5. `CugJournalRankingProvider`在本地 2023 版目录中按“学科 + 规范化期刊名”查找 T1–T6。
6. 达到 50 篇预筛合格候选时停止；扫描 300 篇后仍不足时停止并请求用户决定是否扩大
   检索条件。这里的“预筛合格”不等于“身份已经验证”。

## 组件边界

| 组件 | 属于哪一层 | 责任 |
|---|---|---|
| `LiteratureSearchPlan`、`LiteratureCandidate` | 数据合同 | 限定跨组件传递的数据形状与校验规则 |
| `LiteratureKeywordPlanner` | application/service | 编排一次 LLM 调用并验证结果 |
| `LiteratureDiscoveryService` | application/service | 去重、硬筛选、停止条件与结果汇总 |
| `LiteratureSearchProvider` | port/interface | 隔离上层业务与具体检索平台 |
| `CrossrefSearchProvider` | infrastructure/adapter | 把 Crossref 响应转换成项目数据合同 |
| `JournalRankingProvider` | port/interface | 隔离上层业务与具体分级体系 |
| `CugJournalRankingProvider` | infrastructure/adapter | 读取本地地大目录并返回可追溯的匹配证据 |

## 本地目录数据合同

规范化文件为`data/cug_wuhan_journal_classification_2023.csv`，保留：

- 类别、学科、期刊原名和 T1–T6 等级；
- 原工作簿名与原行号；
- 原始压缩包版本信息和 SHA-256。

目录不是中科院分区，产品界面不得把 T1–T6 显示成“中科院一区/二区”。

同一期刊可能跨学科获得不同等级，因此查询必须带学科。源目录还有 5 组同学科冲突记录；
这类查询返回`ambiguous`并进入排除记录，不自动选择较高或较低等级。

## 为什么不是让 LLM 判断期刊等级

LLM 适合生成关键词，因为这需要语义理解和同义词扩展。期刊等级属于版本化的外部事实，
应由确定性代码查询可追溯的数据源。这样可以避免模型编造等级，也能说明一个结果来自
哪个工作簿的哪一行。

## 失败、降级与停止

- LLM 无法生成合法检索计划：修复一次，仍失败则停止，不进入网络检索。
- Crossref 暂时失败：指数退避，最多重试两次；仍失败则明确报告检索故障。
- 目录中无期刊：候选进入`excluded`，原因是`journal_not_in_cug_2023_catalog`。
- 目录内部冲突：候选进入`excluded`，原因是`cug_2023_catalog_conflict`。
- 合格候选不足 50：流程停止并请求用户确认，不能私自放宽年份或期刊等级。

预筛候选还必须进入下一阶段的 DOI 解析、出版社落地页与官方 RIS 元数据对照，成功后才能
称为“已验证真实文献”。本迭代没有把 Crossref 搜索命中错误地包装成最终验证结果。

Crossref 列表请求默认按公共池每秒一次限流；配置`mailto`时按 polite pool
每秒三次限流。适配器同时带有明确的 User-Agent。

## 验收标准

- 本地目录 15,875 条记录全部通过数据合同加载。
- 已知期刊能够返回正确等级及源行证据。
- 同学科冲突不会被静默覆盖。
- Crossref 元数据能转换成规范 DOI 候选。
- DOI 去重、年份、文献类型和 T 等级筛选可重复、可单元测试。
- 达到 50 篇或扫描 300 篇时按约定停止。
- Fake Provider 测试不访问网络，真实 Crossref 冒烟测试验证集成边界。
