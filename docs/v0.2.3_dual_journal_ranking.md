# V0.2.3：双期刊分级证据

## 为什么增加第二套目录

地大2023目录是面向本校学科的本地分类，不能期待它覆盖 Crossref 中的全部国际期刊。
因此，“地大未分级”只说明本地目录没有给出唯一结果，不表示论文虚假或期刊不存在。

V0.2.3 增加挪威国家学术出版渠道目录（Norwegian Register）2025固定年度等级：

- Level 2：较高层级；
- Level 1：获认可的基础层级；
- Level 0：该年度未获认可；
- 未匹配：快照中没有0、1、2级的唯一记录。

该目录由挪威高等教育与技能署维护。项目使用固定的2025等级和本地快照，
避免每次运行因外部目录实时更新而产生不可复现结果。

## 数据流

```text
Crossref候选
  -> DOI、题名、期刊名、ISSN
  -> 地大2023：学科 + 规范化期刊名
  -> 挪威2025：ISSN优先，规范化期刊名兜底
  -> 两套独立RankingLookup证据
  -> DOI/RIS真实性验证
  -> 相关性 > 地大等级 > 挪威等级 > 年份
```

真实性和期刊分级是两个不同的问题：

- DOI/RIS证据回答“这篇论文及其元数据是否真实、对应”；
- 期刊目录回答“这个期刊在某个固定评价体系和年份中是什么等级”。

论文即使两个目录都未分级，只要DOI/RIS验证通过，仍然是真实论文；在当前软偏好策略下
可以入选，但会在相同相关性时排在已有等级证据的候选之后。

## 为什么优先使用ISSN

期刊题名会出现大小写、空格、连字符、缩写和改名差异。ISSN是更稳定的期刊标识。
适配器先检查Crossref提供的Print ISSN和Online ISSN，只有没有命中时才使用保守的
题名规范化。每个结果保留`match_basis=issn/title/none`，便于调试误匹配。

## 为什么不把两套等级换算成一套

地大T1—T6与挪威Level 0—2的评估目的、覆盖范围和决策流程不同。
把Level 2直接换算成T2会制造看似精确、实际没有依据的结论。因此系统：

1. 同时保存并展示两套原始等级；
2. 先遵守本地地大等级偏好；
3. 仅在排序并列时使用挪威等级补充判断；
4. 明确展示两个目录都没有唯一等级的数量。

这种设计体现解决方案工程中的关键原则：外部事实必须带来源、版本和匹配证据，
不能由LLM凭记忆补全，也不能为方便排序而篡改评价体系的含义。
