# Security and privacy

VeriWrite processes API credentials, local PDFs, course requirements and generated manuscripts.
Do not attach real `.env` files, runtime snapshots, PDFs or unpublished paper text to a public issue.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting or a private Security Advisory for the repository.
Include a minimal reproduction with synthetic data. Remove API keys, local paths, personal identifiers,
course materials and copyrighted full text before submitting.

## Supported version

The current `main` branch is the supported portfolio/MVP version. This is a local-first research
prototype, not a hosted multi-tenant service. Operators are responsible for filesystem permissions,
provider account controls and the AI-use policy that applies to each course.
